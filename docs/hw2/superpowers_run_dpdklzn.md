## Задача и результат

Промпт задания: «Машины старше 20 лет должны сразу получать отказ,
независимо от LTV. Сделай». Источники порога: инструкция пользователя
2026-10-14, `docs/sources/LOAN-12.md` П-3 и существующий
`backend/config/rules.php`, `vehicle.max_age_years = 20`.

Для заявок, валидных по остальным правилам, возраст выше порога теперь
даёт `reject` до сравнений с порогами LTV и пробега в `DecisionEngine`.
Возраст ровно 20 лет не включает новое правило. Численный LTV в ответе
сохраняется; `approved_limit` при отказе равен 0. Возрастной предел
перенесён из ошибки валидации в бизнес-решение, чтобы такие заявки
доходили до движка. Ограничение года `min_year = 1990` и запрет года
в будущем сохранены; для невалидных заявок остаётся ошибка 422.

Действующий HTTP-контракт сохраняет 200 для `/api/ltv` и 201 для
созданной `/api/applications`; меняется классификация валидного
старого автомобиля: вместо прежней ошибки возраста — решение `reject`.
Возрастные лимиты LTV `ltv_by_age` не реализовывались в этой задаче.
