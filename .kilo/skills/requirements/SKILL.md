# Порядок работы
1. Прочитать исходную постановку задачи.
2. Спросить ID задачи, если не указан.
3. Переформулировать требования в фиксированные разделы.
4. Показать результат в чате.
5. Сохранить в `docs/spec/spec_<ID задачи>.md`.

# Формат результата
- «Требования»
- «Границы»
- «Не-цели»
- «Открытые вопросы»

# Чек-лист
- Ничего не додумано сверх исходной постановки.
- Не добавлены новые правила, план реализации, нумерация REQ/AC.
- Границы и не-цели указаны явно.
