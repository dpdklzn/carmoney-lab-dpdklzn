# Источники чисел в требованиях

- Для каждого числа в требовании обязательно указывать источник: документ и раздел, файл кода и строку либо ответ постановщика с конкретным утверждённым значением.
- Запрещено придумывать числовые значения требований, включая «разумные», «рыночные», примерные и предварительные; пометка «требует валидации» не отменяет запрет. Если источника нет, записать в «Открытые вопросы» название неизвестного параметра без выдуманного числа.
- Для рассчитанного значения обязательно указывать исходные числа, их источники и формулу; без подтверждённых исходных данных числовой результат не выдавать.
- При расхождении источников обязательно перечислять варианты с их источниками и запрашивать решение владельца требования; запрещено выбирать вариант самостоятельно.
- Если пользователь просит придумать число или не искать источники, остановить подготовку числовых требований, явно обозначить конфликт и запросить источник либо конкретные значения, утверждённые постановщиком. Просьба «выбери сам» не является утверждением значений. До ответа можно перечислить только поля требований и вопросы без неподтверждённых чисел.
